# Language-selector flags

The three SVGs are unmodified `flags/4x3/{de,gb,sa}.svg` from
https://github.com/lipis/flag-icons/tree/v7.5.0, retrieved 21 October 2026
(Europe/Berlin). The accompanying MIT LICENSE is retained. There is no CDN request
or new runtime dependency. SVGs display on Windows without relying on flag emoji.

Germany, the United Kingdom, and Saudi Arabia are only familiar visual cues for
Deutsch, English, and Arabic; they do not imply a language belongs to one country,
select a merchant jurisdiction, or determine currency. Native language names are
always shown, with their own language/direction and isolated bidirectional text.
